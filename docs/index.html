What It Does

Give it a script and footage, review the generated edit plan, then assemble a reversible rough cut through supported Premiere routes.

Timeline Editing

Inspect, insert, overwrite, move, trim, razor, ripple, and assemble clips from a validated edit plan.

Color Grading

Discover installed effects and apply supported Lumetri/effect parameters with public-DOM readback where Premiere exposes it.

Audio Mixing

Inspect and adjust supported audio levels/effects, analyze waveforms and silence, and build reviewable dialogue-cut plans.

Effects & Transitions

Discover and apply installed effects/transitions through curated routes that check the resulting name, duration, or parameter state.

Planned Workflows

Parse scripts, match assets, validate EDLs, create social variants, and keep a human checkpoint before timeline mutation.

Export & Delivery

Direct export, Adobe Media Encoder queue, codec conversion (ProRes, H.264/265, DNxHR), batch exports, and delivery checks.

Architecture

Four languages, each playing to their strengths:

Go Orchestrator

MCP protocol handling, concurrency, service mesh, health checks, and circuit breakers. The central hub that routes all tool calls.

Rust Media Engine

High-performance media scanning, waveform analysis, thumbnail generation, and real-time processing. When speed matters.

Python Intelligence

Deterministic script parsing, asset matching, EDL generation, and pacing analysis.

TypeScript Bridge

Connects to Premiere Pro via CEP/ExtendScript. Translates MCP tool calls into native Premiere Pro operations.

Quick Start

git clone https://github.com/ayushozha/AdobePremiereProMCP.git
cd AdobePremiereProMCP
just install && just build
just install-panel  # Install CEP panel into Premiere Pro
just start          # Start all services

PremierPro.command starts the full local stack on macOS. PremierPro.bat launches the Windows CLI after its backend services and CEP panel have been started separately.

Supported Versions

The extension manifest targets Adobe Premiere Pro 2020 through 2026 on macOS and Windows. Compatibility still requires a host smoke test on the exact Premiere/OS build. The bridge uses Adobe's CEP (Common Extensibility Platform) and ExtendScript.

Premiere Pro 2020-2022

Declared manifest targets; live compatibility matrix pending.

Premiere Pro 2023-2024

Declared manifest targets; run the host smoke workflow before mutations.

Premiere Pro 2025-2026

Primary/beta development targets; live compatibility matrix pending.
